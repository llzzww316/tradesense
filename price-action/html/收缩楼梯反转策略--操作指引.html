核心逻辑：找到动能衰竭的楼梯结构 → 等反向强 K 确认 → 入场 → 用楼梯极值做初始止损 → 跟进/保本/追踪逐步锁利。

适用场景：5 分钟周期，趋势末期出现收缩结构时。不适合窄通道强趋势中段。

一 策略原理

收缩楼梯的本质是动能衰竭。当一段趋势连续三次同向推进，但每一推的幅度越来越小，说明推动方力量正在枯竭——就像爬楼梯，台阶越来越矮，离顶部不远了。

Al Brooks 指出：

"Whenever shrinking stairs are present, the trade becomes more likely to be successful and usually has a larger profit potential."

为什么收缩楼梯有效？

1
多空力量转换
推进幅度递减 = 顺势方越来越弱，逆势方越来越强
2
止损空间明确
楼梯极值就是最远的止损位，风险可量化
3
目标位可测
反转后通常至少回到楼梯起点，理论空间 = 第一段幅度

1.1 上升楼梯（做空）

L0 ──→ H1 幅度 = leg1（最大） L1 ──→ H2 幅度 = leg2（< leg1） L2 ──→ H3 幅度 = leg3（< leg2） 趋势向上但每一推越来越弱 → 做空 止损 = H1~H3 中的最高点 + buffer 反转方向 = short

1.2 下降楼梯（做多）

H0 ──→ L1 幅度 = leg1（最大） H1 ──→ L2 幅度 = leg2（< leg1） H2 ──→ L3 幅度 = leg3（< leg2） 趋势向下但每一跌越来越浅 → 做多 止损 = L1~L3 中的最低点 - buffer 反转方向 = long

二 信号识别：四道关卡

全部通过才产生入场信号。缺一不可。

关卡 1：摆动点确认

识别方法

一个位置要成为摆动高，需要左右各 N 根 K（默认 3）的 high 都严格低于它；摆动低同理。这是为了确认结构，避免噪音。

注意：摆动点确认是延迟的——必须等右侧 3 根 K 走完才能回头看确认。不会出现 look-ahead。

关卡 2：TBTL 过滤

楼梯跨越的 K 线数 ≥ tbtl_min_bars（默认 10 根）。

如果 6 个摆动点挤在 10 根 K 以内，那不是楼梯，只是噪音。真正的反转需要足够的时间来积累多空力量转换。

关卡 3：收缩结构检测

取最近 6 个交替摆动点（连续同类型只保留更极端的），检查 3 段推进幅度严格递减：

条件说明
3 段同向推进上升楼梯：L→H 三段；下降楼梯：H→L 三段
幅度严格递减leg1 > leg2 > leg3，每段都小于前一段
shrink_ratio默认 1.0 = 任何递减即可；0.8 = 每段 ≤ 前段 80%
全部推进 > 0任何一段幅度 ≤ 0 则放弃

关卡 4：反转信号 K

当前 K 必须是一根强反向趋势 K：

条件参数含义
实体占比 ≥ 50%body_ratio_minK 线实体占整根 K 幅度过半，不是十字星
收盘在极值端 ≥ 60%close_extreme_ratio收盘价贴近 K 线一端，不是长影线
方向与楼梯相反—上升楼梯需强阴线；下降楼梯需强阳线

信号 K 的直觉判断

信号 K 应该让你一眼看出"这根 K 线很有力"——大实体、小影线、收盘贴近一端。如果你需要犹豫"这算不算信号 K"，那大概率不算。

三 入场执行

3.1 入场时机

信号 K 收盘确认后，下一根 K 开盘成交。

手动操作时，信号 K 收盘的瞬间就可以挂单。如果信号 K 是最后一根走完的 K，下一根开盘价就是你的成交价。

3.2 止损设置

方向止损位计算
做多楼梯最低点 - buffermin(L1,L2,L3) - stop_buffer_ticks × tick_size
做空楼梯最高点 + buffermax(H1,H2,H3) + stop_buffer_ticks × tick_size

默认 buffer = 3 跳，防止假突破打止损。

3.3 R 值估算与过滤

重要：R 上限过滤

入场前必须估算风险 R = |入场价 - 止损价|。如果 R 过大，说明楼梯极值离入场价太远，止损空间失控——放弃这笔交易。

回测证明，R 上限过滤是改善策略表现最有效的单一改动：

  • 螺纹钢（波动小）：R ≤ 10 跳效果最佳
  • PVC（波动大）：R ≤ 30 跳效果最佳

实战建议：用 2 × ATR(14) 作为动态 R 上限，自动适配品种波动率。

四 离场管理：四级优先级

优先级从高到低，高级条件触发后不再检查低级。

优先级 1a：硬止损

K 线触及止损价 → 立即平仓，没有任何犹豫空间。

做多：bar.low ≤ stop_price → 平仓
做空：bar.high ≥ stop_price → 平仓

优先级 1b：跟进 K 失败

入场后第一根 K（且仅此一根）如果出现强反向趋势 K → 平仓。

做多后第一根 K 是强阴线 → "follow-through bear" 平仓
做空后第一根 K 是强阳线 → "follow-through bull" 平仓

判断标准与信号 K 相同：实体 ≥ 50%，收盘在极值端 60%。

只检查一次，之后不再触发。

优先级 1c：1R 保本

浮盈达到 1R 时，止损移到入场价。最坏结果变成平局出场，不再亏钱。

计算：做多 (close - entry) / risk ≥ 1.0 → stop = entry
做空 (entry - close) / risk ≥ 1.0 → stop = entry

只执行一次，之后不再调整。

优先级 1d：追踪止损

保本之后，每确认一个新摆动点就把止损追过去：

  • 做多：新摆动低 - buffer（只能往上移，不能下移）
  • 做空：新摆动高 + buffer（只能往下移，不能上移）

摆动点确认用的是 3 根 K 简易判定（前后各 1 根确认），比入场时的增量式检测更灵敏。

4.1 离场流程图

持仓中 │ ├─ 触及硬止损？ ──→ 是 ──→ 平仓（结束） │ ├─ 入场后第 1 根 K 且未检查过？ │ └─ 是强反向趋势 K？ ──→ 是 ──→ 平仓（结束） │ ├─ 未保本 且 浮盈 ≥ 1R？ │ └─ 是 ──→ 止损移到入场价（标记已保本） │ └─ 已保本？ └─ 新摆动点确认？ └─ 是 ──→ 止损追至新摆动点（只往有利方向移）

五 完整决策流程

Step 1 扫描摆动点 每根 K 收盘后，检查是否能确认新的摆动高/低 保持交替摆动点序列（连续同类型只留更极端的） Step 2 检查 TBTL 最近 6 个交替摆动点跨越多少根 K？ < 10 根 → 不够，继续等 Step 3 检查收缩结构 3 段推进幅度是否严格递减？ leg1 > leg2 > leg3？ 任何一段 ≤ 0 → 放弃 Step 4 等待反转信号 K 当前 K 是否是强反向趋势 K？ 大实体 + 收盘在极值端 + 方向与楼梯相反？ 不是 → 继续等，楼梯结构还在 Step 5 估算 R 值 R = |当前收盘价 - 止损价| R > 2×ATR(14)？ → 放弃（风险过大） Step 6 入场 下一根 K 开盘成交 止损 = 楼梯极值 ± buffer Step 7 离场管理 1a 硬止损 → 1b 跟进 K → 1c 1R 保本 → 1d 追踪止损

六 实战要点与常见错误

6.1 实战要点

要点说明
楼梯结构比信号 K 重要楼梯确认了趋势衰竭，信号 K 只是确认反转时机。没有楼梯的强 K 不做。
信号 K 确认后立即行动犹豫 = 错过最佳入场价。信号 K 收盘即挂单。
止损不要缩楼梯极值止损是逻辑止损，缩止损 = 逻辑失效。R 太大就放弃，不要硬做。
保本是转折点1R 保本后，这笔交易从"可能亏"变成"最差平局"，心态完全不同。
追踪止损让利润奔跑保本后不要急着止盈，让追踪止损慢慢推，给反转趋势足够空间。

6.2 常见错误

错误 1：R 值失控仍入场

楼梯极值离入场价很远（比如 50 跳），止损空间巨大。这种交易单笔亏损就能吃掉前面几笔盈利。

正解：入场前估算 R，超过 2×ATR 就放弃。错过一笔不亏钱，做错一笔大出血。

错误 2：逆大趋势做楼梯

日线级别强多头中，5 分钟出现一个收缩楼梯做空信号——大概率被大趋势碾过。

正解：叠加 EMA 趋势过滤。做多要求收盘在 EMA 上方，做空要求在下方。

错误 3：忽略跟进 K

入场后第一根 K 就是强反向趋势 K——说明入场方向错了，但舍不得走。

正解：跟进 K 失败是救命信号，不是干扰。错了就走，等下一个楼梯。

错误 4：追踪止损太灵敏

保本后用 3 根 K 判定摆动点追踪止损，5 分钟级别噪音大，一点小回调就触发。

正解：考虑改用固定比例回撤（如从最高点回撤 1R 平仓），或加大摆动点确认的 lookback。

错误 5：没有止盈目标

纯靠追踪止损离场，盈利交易容易被小回调截断，大利润跑不出来。

正解：设 2R 或 3R 限价止盈。楼梯反转的理论目标 = 第一段幅度，可以量化。
