▲ 做多入场

  • bar.low ≤ 布林下轨价格触及/跌破下轨

  • 或 牛市吞没阳线实体覆盖前一根阴线

▼ 做空入场

  • bar.high ≥ 布林上轨价格触及/突破上轨
  • 上影 Pin Bar实体≤40%K幅，上影≥实体×2
  • 或 熊市吞没阴线实体覆盖前一根阳线
  • 时间过滤不在 14:30-21:00、不在 22:30 之后
3 止损 / 止盈

📐 止损公式

方向止损价
做多入场K最低 − 1.5×ATR
做空入场K最高 + 1.5×ATR

止损放在入场K线极值外侧 — 如果极值被刷穿，说明不是衰竭是延续，认赔。

PVC 15m ATR 通常在 4~8 tick，单笔止损约 6~12 tick。

🎯 止盈价

止盈 = 布林中轨 SMA(20)

不贪 — 均值回归的终点就是回到中轨。

盈亏比通常 1.5:1 ~ 2.5:1

6 风险与对策
⚠ 单边趋势 — 接飞刀
触轨 + Pin Bar 后价格继续朝原方向走（布林带被撑开）
→ ATR止损兜底；连续2次止损后当日停手
⚠ 假突破 — 没有形态就入场
看到触轨就急，不等 Pin Bar/吞没确认
→ 严格等形态：没有 Pin Bar = 不做
⚠ 尾盘噪音
14:30 后成交量萎缩，信号质量断崖下降
→ 14:30 后禁止开新仓（已有持仓可保留）
⚠ 夜盘滑点
夜盘成交量小，止损/止盈触发时滑点比日盘大
→ 夜盘止损可放宽 0.5ATR 留出缓冲
⚠ 带宽过窄 — 横盘无利润
布林带收窄到 5% 以内 → 中轨太近，止盈不够覆盖手续费
→ 带宽 < 5% 时观望，不交易
⚠ 连续亏损 — 情绪追单
连亏后想翻本，放宽入场条件、放大仓位
→ 单日最多亏损 3% 本金即停；初始 1 手不动
