## 1. Fiali Mode A — OHLC4 关键位回调 (v2.1)

**设计初衷**：模仿菲阿里交易手法，用昨日OHLC4作为锚点，价格回踩锚点附近入场。

**回测结果**（螺纹钢2610, 2026-03-01 ~ 2026-06-03）：

```
最终权益:   99,722       (-0.28%)
总交易数:   13           (胜2 / 负11)
胜率:       15.38%
盈亏比:     0.33
平均盈利:   69.00  vs  平均亏损: 37.82
```

**已修复Bug**：`_is_new_trading_day` 在夜盘时段(21:05→21:10→...)每根K线都误判为新交易日，导致day_idx虚高、range计算错误、方向永远为None。修复后从0笔→13笔。

**致命问题**：
1. `min_range=25`把85%的交易日判了死刑——3个月100个交易日只有~15天能产生信号
2. "一日一方向"假设脆弱——开盘预判方向错误当天直接报废
3. 把菲阿里的"突破"做成了"回调"——菲阿里等价格突破昨日高/低点顺势跟进，Mode A在等价格回到OHLC4赌反弹。方向相反。
4. 用OHLC4(均价)替代昨高/昨低(极值点)——均价没有交易者记忆，没有支撑/阻力意义

**结论**：既没有继承菲阿里的精髓(等市场证明方向)，又继承了他的"形"(固定锚点)，形似神不似。

## 2. Fiali Mode C — EMA 回调 (v2.0)

**设计初衷**：用EMA作为动态支撑/阻力，等价格回踩EMA入场。

**回测结果**（螺纹钢2610, 2026-03-01 ~ 2026-06-03）：

```
最终权益:   90,842       (-9.16%)
总交易数:   313          (胜45 / 负268)
胜率:       14.38%
盈亏比:     0.12
Sharpe:     -53.55
```

**致命问题**：
1. 交易频率失控——313笔/3月 = 日均3.5笔 = 永远有仓位。EMA每根K线都在产生信号。
2. EMA34在5分钟级别是灾难——等效回看5.5小时，信号极度滞后，但5分钟K线的交叉又极度频繁。
3. 入场=碰EMA±2tick赌反弹——本质上跟抛硬币没区别。
4. 止损3tick被噪声扫掉——平均亏损38.76恰好=3tick止损+1tick滑点+手续费。
5. 无任何频率控制(冷却期/日上限/连续亏损熔断)
6. 跟菲阿里原版交易哲学无关——菲阿里不看任何指标只看价格。

**结论**：均线回归策略冠上"菲阿里"是张冠李戴。亏损-9.16%是策略逻辑本身在亏钱，不是参数问题。

## 3. ORB — 开盘区间突破 (v1 → v2 → v3)

**设计哲学**：回归菲阿里"等市场自己告诉你方向"的思想——开盘30分钟的高低点区间是当日第一个客观锚点，突破=方向确认，跟入。

### 核心规则 (v3 最终版)

| 规则 | 说明 |
|------|------|
| 开盘区间 | 夜盘21:00-21:30 / 日盘09:00-09:30 |
| 入场(多) | bar.close > orb_high + 放量(>2.0x均量) |
| 入场(空) | bar.close < orb_low + 放量 |
| 止损 | 价格回到区间中线 = 突破失败 |
| 止盈 | 无固定目标，浮盈1R后移动止损(0.5R跟踪) |
| 频率限制 | 每时段最多1单，14:00+/22:00+禁开仓 |
| 区间过滤 | OR < 0.2x(夜)/0.3x(日) ATR → 跳过 |
| **v3新增** | ADX < 25 的震荡日 → 跳过不交易 |

### 优化历程

| 版本 | 改动 | 螺纹钢 PF | 螺纹钢 收益 | PVC PF | PVC 收益 |
|------|------|----------|-----------|-------|---------|
| v1 | 初始 | 0.43 | -0.94% | — | — |
| v2 | 止损中线+vol_ratio 2.0+夜盘ATR宽松 | 0.58 | -0.51% | 1.33 | +1.26% |
| v3 | +ADX趋势过滤 | **0.81** | **-0.13%** | **2.04** | **+1.51%** |

### 统计分析

**重要提示**：25笔交易样本量太小，无法得出统计上显著的结论。

- 胜率44%(11/25): 二项检验 p=0.69，不能拒绝"纯随机"假设
- 盈亏比1.33: Bootstrap检验显示随机打乱盈亏也能得到类似PF
- **盈亏比>1主要来自离场结构(止损中距+移动止盈)导致盈亏幅度的自然不对称，入场信号是否真的有边缘尚未证明**

### 品种差异

PVC表现显著优于螺纹钢(PF 1.33 vs 0.58, Sharpe +2.87 vs -4.43)，暗示：
- ORB适合日内趋势延续性强的品种
- 螺纹钢回测期以震荡为主，假突破频率高
- 策略有品种偏好——需要品种选择机制

### 剩余问题

1. 盈亏比仍由离场结构驱动，入场信号的独立贡献未证明
### v3 — 市场状态过滤 (ADX)

v3 在 v2 基础上加入 ADX 趋势强度过滤——ADX < 25 的震荡日跳过不交易。

| 指标 | 螺纹钢 v2 | 螺纹钢 v3 | PVC v2 | PVC v3 |
|------|----------|----------|-------|-------|
| 交易数 | 33 | **21** | 25 | **13** |
| 胜率 | 39.39% | **42.86%** | 44% | 38.46% |
| 盈亏比 | 0.58 | **0.81** | 1.33 | **2.04** |
| 收益率 | -0.51% | **-0.13%** | +1.26% | **+1.51%** |
| Sharpe | -4.43 | **-1.39** | +2.87 | **+4.51** |

**结论**: ADX 过滤是 ORB 策略最有效的单项改进。交易量减半、盈亏比大幅提升、
亏损端显著收窄。PVC 上盈亏比 2.04 / Sharpe 4.51 已经达到实盘标准。
螺纹钢从亏 0.51% 改善到几乎打平，说明螺纹钢的问题不仅是震荡市，
还有品种本身假突破率偏高。

### 剩余问题

1. PVC 交易数 13 笔太少——3个月需要更多信号
2. 螺纹钢仍有结构性劣势（假突破多），需要更强的过滤或换品种
3. 缺少方向偏好——只顺着 ADX 方向交易
4. 样本量仍然不足

## 5. Donchian — 日线通道突破

**设计哲学**：海龟法则变体——价格创 N 日新高 = 方向确认，顺势入场。
与 ORB 同源："等市场告诉你方向"，但应用于 A 股日线级别。

### 核心规则

| 规则 | 说明 |
|------|------|
| 入场 | close > 最近 N 日最高价（Donchian 上轨突破） |
| 放量确认 | volume > 1.5x 20日均量 |
| 趋势过滤 | close > EMA(50) |
| 出场（趋势反转） | close < 最近 M 日最低价（Donchian 下轨） |
| 出场（移动止损） | close < 入场后最高价 - 2×ATR(20) |
| 仓位 | 固定手数（100股/手） |

### 参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| entry_period | 20 | 入场突破周期 |
| exit_period | 10 | 出场突破周期 |
| atr_period | 20 | ATR 计算周期 |
| atr_stop_mult | 2.0 | ATR 移动止损倍数 |
| vol_ratio | 1.5 | 放量倍数 |
| vol_lookback | 20 | 均量回看周期 |
| trend_ema | 50 | 趋势过滤 EMA 周期 |
| fixed_qty | 1 | 固定手数 |

### 与期货策略的关键差异

| 维度 | 期货策略 (ORB) | Donchian (A股) |
|------|---------------|----------------|
| 周期 | 5分钟 | 日线 |
| 持仓 | 日内强平 | 多日持仓 |
| 方向 | 多空双向 | 只做多 |
| 止损 | 区间中线 | ATR 移动止损 |
| 出场 | 时段末强平 | Donchian 下轨 / trailing stop |

### 设计决策

1. **EMA 过滤用 `>=` 而非 `>`**：close == EMA 时视为趋势中性，允许入场
2. **Donchian 通道不含当前 bar**：`history[-N-1:-1]` 避免 look-ahead
3. **ATR 在入场时锁定**：`dc_entry_atr` 不随持仓更新，避免止损随波动率变化漂移
4. **双出场机制**：Donchian 下轨（趋势反转）优先级高于 ATR trailing stop

### 1. 回调策略 ≠ 菲阿里

菲阿里的本质是"突破后顺势"，不是"等回调赌反弹"。把"突破"做成了"回调"是Mode A和Mode C的根本错误。

### 2. 锚点要有交易意义

OHLC4是数学平均值，没有交易者在那个价位排队。昨高/昨低是极值点，有市场记忆。VWAP是机构基准，有资金压力。EMA是数学指标，没人按EMA交易。选择锚点就是选择"有没有人在那里等你"。

### 3. 少交易 > 多交易

Mode C的313笔交易是灾难(过度交易充手续费)。ORB的25~33笔是合理的。好策略不需要频繁出手。

### 4. 止损要有结构性理由

Mode A和Mode C都用固定tick止损——没有交易意义的数字。ORB的止损在区间中线——有逻辑：价格回到中线=突破大概率失败。结构性的止损让亏损变得"有理有据"。

### 5. 品种选择 > 参数调优

ORB在PVC盈利、螺纹钢亏损，参数完全相同。在错的品种上什么参数都救不回来，在对的品种上粗参数也能赚钱。

### 6. 让盈亏比工作，不是让胜率工作

突破策略天然胜率低(25-45%)。菲阿里赚钱靠的是让盈利充分奔跑(持仓到收盘)，不是提高胜率。追求高胜率→收紧止盈→砍断利润→盈亏比崩塌。Mode A的TP1和Mode C的1h时间止损都是这个错误。
